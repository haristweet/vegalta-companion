# ベガ観戦のお供

ベガルタ仙台の試合を見ながら使う、スマホ向けの単体 HTML。

## 機能（v0.1.0）

- **3モード切替**：ホーム（黒×金）／アウェイ（白地）／DAZN（黒×蛍光）。いまは配色だけの違い
- **選手名鑑**：背番号・名前・ポジション・期限付き移籍。検索、追加・編集・削除
- **シーズン管理**：「新シーズンを作る」で前季の選手をコピー → 名鑑で直す。シーズンごとに保存
- **スタメン**：フォーメーション6種（4-4-2 / 4-3-3 / 4-2-3-1 / 4-1-4-1 / 3-5-2 / 3-4-3）、ベンチ9人、対戦相手メモ、テキストで共有
- データは端末の localStorage に保存。「書き出し／読み込み」で機種変更に対応

## 初期データ

クラブ公式サイト（トップチーム）の 2026/27 掲載分。背番号・名前・ポジションのみ。
生年月日・身長などは公式の一覧ページに載っていないため入れていない。
