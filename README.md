# ベガ観戦のお供

ベガルタ仙台の試合を見ながら使う、スマホ向けの単体 HTML。

## 機能（v0.2.1）

- **3モード切替**：ホーム（黒×金）／アウェイ（白地）／DAZN（黒×蛍光）。いまは配色だけの違い
- **選手名鑑**：背番号・名前・ポジション・期限付き移籍。検索、追加・編集・削除
- **シーズン管理**：「新シーズンを作る」で前季の選手をコピー → 名鑑で直す。シーズンごとに保存
- **スタメン**：フォーメーション6種（4-4-2 / 4-3-3 / 4-2-3-1 / 4-1-4-1 / 3-5-2 / 3-4-3）、ベンチ9人、対戦相手メモ、テキストで共有
- **試合**：今季の試合結果（勝点・勝分敗・得失点）、次の試合と今季の対戦成績、このあとの日程。試合を押すと経過・メンバー・データ
- **選手名鑑の成績**：出場数・先発数・出場時間（目安）・得点・警告を各選手に表示
- **スタメン**：「前の試合のメンバーを読み込む」、試合画面から「このメンバーを読み込む」、対戦相手を入れると今季の対戦結果を表示
- データは端末の localStorage に保存。「書き出し／読み込み」で機種変更に対応

## 初期データ

クラブ公式サイト（トップチーム）の 2026/27 掲載分。背番号・名前・ポジションのみ。
生年月日・身長などは公式の一覧ページに載っていないため入れていない。
背番号41は公式ページ内で写真の代替テキストと名前が食い違っていた（髙橋 一平で登録）。

## 試合データ（matches.json）

ベガルタ仙台オフィシャルサイトの試合記録・日程ページから作る（監督・選手のコメントは入れない）。
作るのは hari の Mac の `update_companion.command`（SSD の 40_models/vegalta-companion/）。試合のあとにダブルクリックすると、記録の取得 → matches.json の作成 → このリポジトリへの反映まで行う。
出場時間は交代の分から出した目安（アディショナルタイムは数えない）。
